# 居住地・来訪地域集計の独立レビュー

確認日：2026-11-10。実装担当とは別の担当が、作業中のソースと試験定義を読み取り確認した記録。対象ソースの編集、稼働DBの操作、外部への送信は行っていない。

直接の他人プロフィール更新、事業者の閲覧範囲を越える参照、未同意者の市区町村出力は、今回読んだ経路では見つからなかった。少人数の再訪・初回内訳については、**当該市区町村全体を集計表示から外す修正**を再確認した。一方、重なる期間や異なる取得時刻を比較する差分推測は残る。現仕様は**少人数セルの非表示**であり、完全匿名化や個人の推測不能を保証するものではない。

## 少人数セルの修正再確認

`community/backend/app/analytics/origins.py:43` の `visible_areas()` を再読した。現在の規則は次のとおり。

- 市区町村の来訪者が5人未満なら、その市区町村の要素を `areas` に追加しない。
- 来訪者が5人以上でも、再訪者または初回者のどちらかが1〜4人なら、市区町村全体を `areas` から外す。
- 省かれた市区町村について、市ID・市名・代表点・来訪者数・再訪者数・延べ回数の組合せを返さない。全体の省略人数だけを合計する。
- 再訪・初回の各内訳が0人または5人以上の市区町村だけを表示する。

以前の「市名と人数を残し、再訪者数・延べ回数だけをnullにする」形式では、全体の件数との引き算で小さい内訳を復元できる場合があった。最新の市全体省略はこの直接の組合せを除いており、APIの説明文も同じ規則へ更新されている。

`test/backend/test_residence.py` の `test_small_returning_and_complementary_groups_hide_the_entire_city` は、再訪2人＋初回4人と、再訪5人＋初回1人で `areas=[]` を要求している。ほかに、未同意・未設定・5人未満の市区町村除外、同意撤回直後の除外、未来・取消開催の除外、同一事業者の過去利用だけを再訪へ算入する試験定義を確認した。

**この再確認は実装と試験定義の静的確認である。** このレビュー担当は当該試験を新たに実行しておらず、成功件数は主担当・試験担当の実行記録で確認する。

## 残るリスクと表示上の限界

**RS-01：重複期間・取得時刻間の差分推測（設計上の残リスク）。**

例えば、30日集計である市が5人、90日集計で同じ市が6人の場合、どちらの単独セルも表示条件を満たす。事業者が自社開催の参加者を別途知っていれば、差分1人の現在の市区町村を推測できる場合がある。同じ期間を異なる時刻に取得し、人数が1人変化した場合にも同種の限界がある。今回の市全体省略だけでは、過去に取得された集計や背景知識まで制御できない。

現実装はノイズ付与、複数回答にまたがる照会予算、固定した匿名集団での公開を行っていない。そのため「個人を特定できない」「完全匿名化」「差分プライバシー適合」とは表現しない。APIの説明文は、少人数非表示の範囲と期間・取得時刻を比較した推測の限界を明記している。より強い匿名集計が必要な場合は、重複期間の補完抑制、公開間隔、精度を落とす集計などを別の要件として設計・検証する。

同意撤回は次回取得の市区町村集計から反映される。利用者や事業者が以前に見た画面・手元へ保存した内容を遡って消す機能ではない。地図は現在の登録市区町村を使うため、訪問当時の居住地や実際の出発地の計測結果とも区別する。

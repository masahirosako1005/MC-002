# 反復評価台帳

## 運用

実装→検証→測定→課題選定→修正→再検証を繰り返す。これはPJ独自の進捗・品質指標であり、大会の公式点や実再訪率ではない。合格した証拠がある項目のみ加点。未検証は0点で分母に残す。安全性の重大問題、データ破壊、起動不能があれば総点にかかわらず提出不可。

同じ評価項目と条件で前回との差を記録する。自動テストの数を増やすだけで点を増やさない。項目・重みの変更は別版とし、旧点と直接比較しない。定量評価の下降は原因を調査・修正し、重要な仕様変更や再訪体験の取捨選択が必要な場合に利用者へ意見を求める。通常の不具合修正は自律的に進める。

## 固定した20項目（各5点、合計100点）

| ID | 項目 | 合格証拠 |
|---|---|---|
| Q01 | Aの訪問→謎解き→実績→次季保存 | 一連の操作試験 |
| Q02 | Bの空き時間→周遊→次回保存 | 時間制約を含む操作試験 |
| Q03 | 季節・難易度の違い | 異なる内容と版の検証 |
| Q04 | 神社・海辺の再訪機会 | 選択・保存の確認 |
| Q05 | 時系列・候補・実績の区別 | 状態遷移と表示の検証 |
| Q06 | スマホ表示と文字拡大 | 320/390/430px、拡大の手動記録 |
| Q07 | キーボードとアクセシビリティ | 自動検査＋主要操作手動確認 |
| Q08 | 日本語と状態フィードバック | 文言・空状態・失敗・再試行の確認 |
| Q09 | 正常系の主要API | 統合テスト |
| Q10 | 同時操作・再送の整合性 | 重複・並列更新テスト |
| Q11 | 権限・入力・CSRF | 改変・越権・不正オリジンのテスト |
| Q12 | 秘密保護・依存・実行設定 | セキュリティレビューと依存検査 |
| Q13 | 再起動後の永続化 | 再起動前後の保存比較 |
| Q14 | バックアップ復元 | 復元結果の比較 |
| Q15 | 保存障害の原子性 | 障害注入とロールバック検証 |
| Q16 | Dockerと外部通信なしの起動 | コンテナ起動と通信遮断試験 |
| Q17 | 保守性と再現手順 | 設計契約、起動手順、ビルド確認 |
| Q18 | サンプル取込品質と保護 | 重複・不正行検証、元データ不変 |
| Q19 | 評価根拠と調査の採否 | 基準対応表・出典・未達記録 |
| Q20 | プレゼンとデモ | 資料の表示確認とデモ通し |

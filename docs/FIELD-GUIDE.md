# 現地しおり・操作確認用

この資料は運営・発表用です。コードはアプリの公開カタログAPIには含めません。架空のモデル都市をPC上で検証するときは、この資料を別に開いて入力します。

| 場所 | 訪問コード | 体験 |
|---|---|---|
| 四季の水門 | GATE-314 | 今の季節の水門を解く |
| 桜社 | SAKURA-428 | 訪問を記し、希望する節目を選ぶ |
| 凪の海辺 | COAST-582 | 訪問を記し、別の季節の活動を選ぶ |
| 水都国際会議館 | MEET-763 | 会議から周辺の旅へつなぐ |

## 発表の操作例

1. 四季の水門で訪問を記録する。
2. 現在の季節の「はじめて」を選ぶ。
3. 手掛かりの合計と2つの水門の値から、残りを求める。
4. 達成と実績を確認し、次の季節の体験を保存する。
5. 旅の手帳で訪問・実績を確認する。
6. 次の旅で会議の空き時間を選ぶ。海辺30分では足りず、180分では候補となることを確認する。営業時間外の現季節は候補がないので、将来季節の計画を表示する。
7. 保存した候補を開き直し、記録が残ることを見せる。

資料のコードを知っていれば現地以外でも入力できるため、操作デモの訪問記録を実際の現地再訪として数えない。

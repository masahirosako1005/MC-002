# 20秒の操作紹介動画（CP44）

状態：2026年11月9日、CP43最終UIの配信・受入確認後に実録画・書き出しを完了。20.000秒、1440×900、30fps、H.264、600フレーム、1,088,505 bytes。制作担当がコンタクトシートと原寸のログイン・行程・クリック画像を確認済み。主担当もコンタクトシートと原寸フレームを確認し、文字・強調位置・判断情報を受入済み。

## 構成

1440×900の左右二台画面をそのまま録画する。無音、約20秒。公開されたローカルのプランを読み取り操作で開き、保存・招待・予約・評価は行わない。

| 時間 | 実操作 | 字幕・強調 |
|---|---|---|
| 0–4秒 | 入力済み・パスワード非表示の画面から実ログイン | 「アカウントを入力して、ログイン」。旅行者の入力欄・ログイン操作を明るくする |
| 4–9秒 | 公開プランを短い検索で絞り、写真を見る | 「写真を見ながら、旅のプランを探す」。検索欄と実際のカードを強調 |
| 9–15秒 | 写真をクリックし、詳細の人数・泊数・エリア・料金を読む | 「人数・泊数・エリアを確かめる」「料金と、費用に含まれる内容を確認」 |
| 15–20秒 | 詳細をスクロールし、行程・訪問先を読む | 「行程・訪問先まで、詳しく確認」 |

実DOMの矩形にiframeの表示位置を足してスポットライトを置く。対象外は暗くするが、字幕と対象は読める明るさを保つ。クリック位置には小さなリングとカーソルを添える。録画用の一時オーバーレイだけを追加し、アプリ内容・成功表示・登録情報を置き換えない。

初回はアプリのCSPがinline stylesheetを拒否したため、字幕開始位置の検査で書き出しを停止した。完成版は録画contextだけで同一originのCSSリソースを供給し、アプリのCSP・サーバー・ソースを変更せずに再録画した。初回の操作記録は`recording-first-attempt.json`に保持し、完成版と区別する。

公開された初期アカウントを使用し、入力済みのパスワードは常に伏せ字。秘密ファイルは読まず、パスワード入力操作や認証値を動画・ログに含めない。ネットワークはローカルだけに制限し、ログイン以外の書き込み要求を拒否する。通常Edgeの既存プロファイルではなく、分離したヘッドレスEdgeで撮影する。

## 生成と確認

- `node community/scripts/create_intro_video.mjs --prepare`：依存を確認する。ブラウザーは起動しない。
- `node community/scripts/create_intro_video.mjs --record`：実画面を録画し、20秒のMP4へ書き出す。
- 出力：`outputs/community-intro.mp4`、`outputs/community-intro-poster.png`。
- 根拠：`community/artifacts/intro-video/recording.json`、`verification.json`、キー画像、`contact-sheet.jpg`。
- 元のWebMから字幕が現れた開始位置を検出し、その後20秒を等速で取り出す。冒頭0.15秒・末尾0.3秒だけ黒へフェードする。H.264、1440×900、30fps、yuv420p、無音。
- FFmpegで完成MP4を全フレーム復号し、20±1秒・600フレーム・寸法を確認する。さらにコンタクトシートとキー画像で字幕・位置・実画面を目視確認する。目視確認前は成功と記録しない。

完成版はJS例外0件、外部要求0件、ログイン以外の書き込み0件。入力済みの伏せ字から左右の実ログイン、旅行者による「森」の検索、公開プランの写真クリック、人数・料金・行程のスクロール閲覧を行った。元動画の2.1667秒付近から20秒を等速で使用した。通常Edgeの既存停止問題や、そのほかの画面の動作品質までこの動画で証明するものではない。

依存：既存の`qa/node_modules`のPlaywrightとインストール済みEdge、プロジェクト`.venv`の`imageio-ffmpeg==0.6.0`（同梱FFmpeg 7.1、libx264対応）、Pillow。Playwrightの録画用FFmpegは`.tools/playwright-browsers`へ配置し、アプリの実行時依存にはしない。

準備で確認した公式資料：[Playwrightの動画記録](https://playwright.dev/docs/videos)、[imageio-ffmpegの配布情報](https://pypi.org/project/imageio-ffmpeg/)。Playwrightはcontext終了時に記録を確定するため、終了を待ってから変換する。

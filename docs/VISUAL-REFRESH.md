## 画像の制作と配置

利用者指定の imagegen スキルを用い、組み込み画像生成で制作した。モデル名を選択・確認できないため特定のモデル版の使用は主張しない。開発時の生成だけに利用し、完成アプリから画像生成サービスへ接続しない。

- 水門の春・夏・秋・冬、桜社、凪の海辺、会議館、街の見取り図の8点。
- 水門は秋の原画から季節だけを変更し、建物と視点を維持。同じ場所の違う季節を視覚で伝える。
- 原画PNGは `artifacts/image-originals/`、配信用WebPは `frontend/public/art/`。
- `scripts/prepare_art.cjs` で構図を変えず幅640/1280へ縮小・圧縮。原画約30.6MB、表示用16ファイル合計約3.86MB。画面で実際に取得する量は画面幅と閲覧箇所で異なる。
- 原画は不変で保持し、出力名はv2。プロンプトは `IMAGE-PROMPTS.json` と `IMAGE-PROMPTS-SEASONS.json`、寸法・バイト数・ハッシュは `artifacts/art-manifest.json`。
- 場所名・操作・地図ラベルは画像へ焼き込まず日本語のテキストで表示。装飾画像は読み上げ対象外。機能アイコンと季節印は拡大しても鮮明なSVGを維持する。

## 収集体験の判断

6サービス・7つの仕組みを公式公開資料で比較した。既存サービスの徽章・キャラクターを複製せず、行動と収集の関係を独自の記念品へ適用する。楽しさの改善は設計上の仮説であり、実利用者で測った効果ではない。

| Before | After | Why |
|---|---|---|
| 春夏秋冬の達成印と時系列だけ | 場所・季節・続く旅の3棚と12種の記念品 | 今回の旅と将来の旅に異なる集め方を用意する |
| 未達は「これから」だけ | 条件、実進捗、取得記録日、次に進む場所/季節 | 自分で狙いと次の行動を選べるようにする |
| 一度達成したら表示が固定 | 別日・別季節・奥の水路で段階を進める | 同じ場所へ戻る具体的な続きを作る |
| 目標を記録できない | 次に狙う1点を手帳へ保存 | 次回や別ブラウザーへの復旧でも狙いを思い出せる |
| 幾何学的な景観 | 手描きの質感と細部を持つ8枚の風景画 | 地域や季節を眺める楽しさを増やす |
| 標準の選択部品が画面から浮く | 選択/フォーカス/余白/説明を他の操作部品と統一 | 操作を予測しやすくし、スマホでも選びやすくする |

現地訪問コードは実在位置を保証しない。別日記録は独立した旅行の再訪証明ではない。訪問だけで会議出席・宗教行事・海のアクティビティを達成したと推定しない。偽の希少率、抽選、日次ストリーク、失効する記念品は採用しない。

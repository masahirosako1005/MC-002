# チケット管理の検証記録

2026-11-09、Windows・Python 3.13.17、PJ内の仮想環境で確認した。既存の観光アプリ試験とは別の管理ツールの確認であり、観光アプリの成功件数へ加算しない。

## CLI・データ保存

コマンド: `.venv/Scripts/python.exe -m unittest discover -s scripts -p test_tickets.py -v`

結果: 6件成功。以下を合成チケットで確認した。

1. 全受入条件と証拠が揃う前の完了を拒否し、再開には理由が必要。
2. 過去のイベントのバイト列を保ち、イベント保存直後にJSON更新を失敗させても、次の読取で追記済み変更を回復。
3. 4つの同時コメント更新で欠落・連番重複を生じない。
4. `</script>` 等の入力を安全に埋め込み、PJ外パス・外部リンクを拒否。
5. 改変された試験用イベントを検出し、正本や履歴を自動上書きしない。
6. TASKSの二重取込でチケットを増やさず、受入条件と依存を保持。

実データの初期整理後に `scripts/tickets.py validate` を実行し、24件・イベント73件の正本と履歴が一致した。この件数は起票時点の記録で、以後の正当な更新により増える。

# 旧版 v1.1 の保管

スタンプ・謎解き・トロフィーを中心とした旧アプリを、将来の再利用のために保管した。新しいコミュニティ版の完成物ではない。

- `source-with-history.zip`：旧版のソース、設計、発表資料、試験、Git履歴を含む配布物。245ファイル、85,610,168 bytes。
- `archive-manifest.json`：元ZIPと一致するSHA-256、CRC検査、対象リビジョンの記録。
- `DESIGN.md` / `TASKS.md` / `APP-README.md` / `EVALUATION.md`：旧版の読み合わせ用コピー。
- 対象Gitコミット：`05c3d878e1a42a3f62cdcb704e415282ea5af8ac`。

ZIPはPJ内に実体を置くが、大きな配布物の重複を避けるためGitの対象外とする。旧コード自体はGit履歴にも残る。復元時はPJ内に新しい空フォルダを作って展開し、アプリの起動手順を読む。既存の作業フォルダへ直接上書きしない。

稼働中のDB・個人情報・秘密・依存キャッシュはZIPに含めていない。旧DBは既存Docker volumeに残っている。旧コードの物理移動や停止は今回の設計作業では行わず、新版の実装時に入口と保存先を分離して切り替える。現在のルートの起動手順で起動するのは旧版である。

新方針の正本は [設計書](../../DESIGN.md)、次の作業は [タスク](../../TASKS.md)。旧版の試験合格や評価点を新機能の検証結果へ転用しない。

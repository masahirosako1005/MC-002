# tang you chi フロントエンド

React・TypeScript・Viteによる日本語Web UI。実行時の通信先は同一オリジンの `/api` のみ。書体はOS搭載書体、挿絵と見取り図はリポジトリ内のオリジナルSVG。地図配信、CDN、外部分析ツール、外部画像は使わない。

## 開発とビルド

Node.js 24で確認。

```powershell
npm ci --ignore-scripts
npm run dev
npm run build
```

開発サーバーは127.0.0.1にのみ待受。`/api` を同一マシンの `127.0.0.1:8000` に転送する。API側で開発UIのオリジンを明示許可すること。完成環境では親ディレクトリのDocker構成で `dist/` を配信し、同一オリジンのAPIへ接続する。

## データと安全性

- セッション識別子はサーバー発行のHttpOnly Cookie。CSRFトークンはメモリ内のみ。localStorageとsessionStorageへ認証情報を保存しない。
- 書込通信はJSONとX-CSRF-Tokenを使う。復旧後にCSRFを更新し、旧手帳の表示を消して再取得する。
- 訪問コード・謎の解答・得点計算をフロントエンドへ埋め込まない。季節制限、所有者、重複、不正入力の最終判定はサーバーが行う。
- 文字列は通常のReact描画を通す。HTML挿入、文字列コード実行、動的な外部URL、外部スクリプトを使わない。
- 引継合言葉は明示発行した画面にだけ表示し、閉じると消す。自動コピーやブラウザー保存は行わない。
- 待機中の更新ボタンを無効化し、二重送信もコード内のロックで抑止。通信失敗を成功として扱わない。
- APIエラー、空の手帳、推薦0件、未公開季節、未獲得季節を分ける。「次の旅」の保存は訪問実績を増やさない。

## アクセシビリティと検証

ネイティブbutton/input/select/dialog、見出し階層、入力ラベル、読み上げ用の処理結果、キーボードの水門操作、フォーカス表示、本文スキップを用意。画面拡大を禁止しない。文字サイズ切替と `prefers-reduced-motion` に対応する。動きを減らす設定とキーボード操作では押下の変形を行わない。

ビルドは `npm run build` で型確認と配信用生成をまとめて行う。ブラウザーの実操作・画面幅・外部通信・アクセシビリティの検証は親ディレクトリの `qa/` と `artifacts/` を参照。実際の再訪増加や包括的な規格適合は主張しない。
